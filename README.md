# SOAP Server in Go

This project implements a SOAP server in Go that handles SOAP requests and sends XML-formatted responses. The server is designed for a simple service called "HolaMundo," which returns a personalized greeting based on the name received in the request.

## Technologies
- Go 1.23.3
- SOAP (Simple Object Access Protocol)
- XML
